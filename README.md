# Miniprojet-QA

## Introduction

**Pourquoi ce projet ?**

Ayant parcouru le syllabus ISTQB foundation level v4.0, l'idée de mettre en pratique ces connaissances acquises m'est parvenue.

**But de ce projet ?**

Il a pour but d'évaluer mes capacités en autodicate à comprendre les axes de compréhension que doit adopter un testeur QA. Apprendre à rediger tout type d'artéfact, et appréhender différentes techniques dans cet exercice.

# Périmètre de mon test exploratoire

## Couverture :
    - Windows 11  Version 25H2 (build système 26200.8457)
    - Microsoft EDGE

### Périmètre de mon objet de test :
    Objet de test : Panier
        - Ajout d'un item 
        - Suppression d'un item
        - Modification de la quantité
        - Affichage du montant
        - Mise à jour du montant selon la quantité
        - Persistance du panier
        - Affichage des produits
        - Gestion des erreurs (quantité invalide, produit indisponible)

#### Hors Périmètre de mon objet de test :
        - Création ou connexion d'un compte
        - Renseignement d'information
        - Procédure de paiement

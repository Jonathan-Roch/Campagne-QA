## Title

Montant qui ne se met pas à jour après la modification par une valeur négative

## Severity

Moderate

## Priority 

P3

## Status

En cours

## Environment

Windows 11 / Microsoft EDGE

## Steps to reproduce

1. Depuis la page produit, clic sur n'importe quel item
2. Appuyer sur le bouton **Add to cart**
3. Aller dans le panier
4. Mettre une quantité négative dans le champ

## Expected result

Le montant total se remet à 0

## Actual result

Le montant total garde en mémoire l'ancien montant

***Voir Observation 5 dans **rapport-exploratoire.docs** pour l'analyse.***
